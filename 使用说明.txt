最新传奇发布网 · 静态站点使用说明
====================================

index.html      首页

hj.html         栏目：合击传奇（20篇）

sitemap.html    HTML 站点地图

aicqsf2026indexnow.txt  IndexNow 密钥文件（必应加速收录）

二、部署到 aicqsf.github.io
------------------------------------
1. 新建/进入 GitHub 仓库 aicqsf（仓库名必须是 aicqsf.github.io，否则需要开 Pages 并配路径）。
2. 把本目录下所有文件（含 .nojekyll）上传到仓库根目录，不要放进子文件夹。
3. 仓库 Settings → Pages → Source 选择 “Deploy from a branch”，分支 main，目录 /(root)，保存。
4. 1～3 分钟后访问 https://aicqsf.github.io 确认首页可打开。
5. 上传后把 sitemap.xml 里的域名核对一遍（当前写的是 https://aicqsf.github.io）。

三、提交搜索引擎（决定收录速度）
------------------------------------
百度：
1. 打开 百度搜索资源平台 → 用户中心 → 添加网站（https://aicqsf.github.io）。
2. 验证方式选「文件验证」，把平台给的 HTML 验证文件放到仓库根目录再提交。
3. 进入「普通收录 → sitemap」，提交 https://aicqsf.github.io/sitemap.xml。
4. 站点已验证后，每页底部的百度自动推送脚本开始生效，新页面会主动推送。
5. 「普通收录 → API 提交」可再补充一次全量提交（109 条）。
360：
1. 360 站长平台 → 添加站点 → 验证（同样用文件验证）。
2. 提交 sitemap：https://aicqsf.github.io/sitemap.xml。
3. 360 对更新频率敏感，保持每日新增/更新 1～2 篇即可。
必应：
1. Bing Webmaster Tools → 添加站点 → 验证。
2. 提交 sitemap.xml。
3. 使用 IndexNow 加速：密钥文件 aicqsf2026indexnow.txt 已在根目录，
   每次上新后向 https://api.indexnow.org/indexnow 提交 URL 即可（详见官方文档）。

四、收录与排名的实操建议
------------------------------------
1. 域名：github.io 子域可被收录，但权重低于独立域名与备案域名。若长期做，建议尽早换成
   已备案的独立域名，并在 GitHub Pages 绑定自定义域名，全站 canonical 一起替换。
2. 开服表：每天把 OPEN_TABLE 对应的 8 条开区信息改成真实数据，标题里的日期同步更新，
   这类“当日更新”的信息型页面最容易被快速收录。
3. 内容：100 篇为原创撰写，但部分段落存在同栏目内的复用。要打排名，建议每周手动改写
   3～5 篇，补充真实版本细节（开区时间、倍率、地图名），把重复度降下来。
4. 内链：每篇文章已有面包屑、上一篇/下一篇、同栏目相关阅读 4 条、侧栏热门 10 条，
   发布新文章时保持这个结构即可。
5. 更新节奏：固定每天 08:30 前更新首页开服表，每周新增 5～10 篇，坚持一个月以上。

五、修改入口
------------------------------------
站点由 _build 目录下的 Python 脚本生成（build.py + cfg.py + content_*.py + more*.py + style.css）。
改文案或加文章后，在该目录执行：python3 build.py，产物会重新写入本目录。
若不再使用脚本，直接编辑 .html 也可以，注意同步修改 sitemap.xml。
